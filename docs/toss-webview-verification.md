## 콘솔 업로드 준비

1. [Apps in Toss 콘솔](https://apps-in-toss.toss.im/)에서 워크스페이스와 미니앱을 선택합니다.
2. 실제 appName·브랜드 색상을 위 표와 대조합니다.
3. `앱 출시` → `등록하기`에서 검증한 `.ait` 파일을 업로드합니다.
4. 업로드 완료 후 `토스앱 테스트`에서 QR/테스트 앱스킴을 확인합니다.
5. 테스트할 기기의 Toss 앱에 로그인한 워크스페이스 멤버가 실행합니다. 현재 안내의 연령 조건도 확인합니다.
6. 현재 콘솔의 메뉴 명칭이 다르면 실제 UI를 기준으로 경로를 기록합니다. 검토 요청·출시 버튼은 이번 작업 범위에 포함하지 않습니다.

현재 공식 가이드는 번들 업로드 후 실제 Toss 테스트를 최소 한 번 완료해야 검토를 요청할 수 있다고 안내합니다. 위 메뉴와 QR 절차의 계정 내 실물 화면은 아직 확인하지 않았습니다. [미니앱 등록하기](https://developers-apps-in-toss.toss.im/guide/operation/console-workspace)
